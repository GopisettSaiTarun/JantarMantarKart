# 🛒 JantarMantarKart

### Premium E-Commerce Shopping Experience

JantarMantarKart is a responsive e-commerce website built as part of Sprint 1 development. The project focuses on creating the foundation of an online shopping platform with product browsing, product details, cart management, quantity updates, and price calculation.

---

## 🚀 Project Overview

JantarMantarKart provides a simple and modern shopping experience where users can:

- Browse products
- View detailed product information
- Add products to the shopping cart
- Increase or decrease product quantity
- Remove products from the cart
- Automatically calculate subtotal
- Calculate shipping charges
- Calculate the final total
- Maintain cart data using browser LocalStorage
